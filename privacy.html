Home Backups: Privacy Policy

Last updated 5 October 2026

The short version

Home Backups is a private tool used only by its owner. It copies encrypted backup files from the owner's own home server into the owner's own cloud storage. It collects nothing about anyone, and nothing is sold, shared or used for advertising.

What it can reach

  • Google Drive, only files it creates (drive.file). It creates one "Home Backups" folder and the backup files inside it, and can see and change only those. It cannot see any other file in the Drive.
  • Microsoft OneDrive, only its own app folder (Files.ReadWrite.AppFolder). It can see and change only the files in Apps/Home Backups.

How the backups are protected

  • Every backup is encrypted on the owner's server, with a passphrase only the owner holds, before it is uploaded. Google, Microsoft and anyone else see only unreadable files.
  • The permission to reach the owner's storage is kept on the owner's own server, encrypted. It is not stored anywhere else and is not sent to any other party.
  • There is no Home Backups server, account, analytics, tracking or advertising of any kind.

Google API Services User Data Policy

Home Backups' use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

In practice: data reached through these permissions is used only to store and restore the owner's own backups. It is never sold, never transferred to anyone, never used for advertising, and never read by anyone except the owner, when restoring his own data.

Removing access

  • Google: myaccount.google.com/permissions
  • Microsoft: account.live.com/consent/Manage
  • Backup files stay in the owner's own storage until the owner deletes them.

Changes and contact

If this policy changes, the new version is posted on this page with a new date at the top. Questions: through the owner's GitHub profile, github.com/Pr0t3ct0r.
